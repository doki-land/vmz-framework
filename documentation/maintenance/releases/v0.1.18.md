# v0.1.18

## Features

- Attach absolute `SourceSpan` to template `invalid-expr` diagnostics ([@aster](https://github.com/aster))
- Route `@vmz/vmz` through `createCli` and `@vmz/diagnostic` ([@aster](https://github.com/aster))
- Allow `@vmz/diagnostic` wire `message` when catalog lacks `code` ([@aster](https://github.com/aster))
- Implement `@vmz/commander` parse/help with localize plug-in ([@aster](https://github.com/aster))
- Wire CLI help and gate errors through `vmzCliLocalize` ([@aster](https://github.com/aster))
- Add `vmz plan` on `@vmz/vmz` via N-API loaders ([@aster](https://github.com/aster))
- Add vmz plan CLI for LocalePlan and DocumentRoutePlan ([@aster](https://github.com/aster))
- Validate template expressions through shared oxc snippet parse ([@aster](https://github.com/aster))
- Convert diagnostic byte offsets to line:column in CLI ([@aster](https://github.com/aster))
- Attach absolute SourceSpan to template parse diagnostics ([@aster](https://github.com/aster))

## Bug Fixes

- Drop dead VS Code LSP client and center docs on `@vmz/vmz` ([@aster](https://github.com/aster))
- Limit Direct host contents box to inline chips ([@aster](https://github.com/aster))
- Remove native CLI forward surface from `@vmz/vmz` ([@aster](https://github.com/aster))
- Prefer JSON for `*/*` Accept; HTML only for document navigations ([@aster](https://github.com/aster))
