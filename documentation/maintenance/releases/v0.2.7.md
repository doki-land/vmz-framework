# v0.2.7

Oak/Nyar frontend integration phase A–D: `vmz-oak-frontend-adapter`, Oak CST/AST template and script lowering, Nyar projection contract, and `oak-frontend-smoke` verify gate. Oaks git deps resolve from `yggdrasil-language/oaks` `dev` on CI.

## Features

- Add `vmz-oak-frontend-adapter` with language-neutral `TemplateShellInput` / `ScriptShellInput` and Oak CST parse ([@aster](https://github.com/aster))
- Wire Oak Vue AST adapter and smoke-gated concrete lowering path ([@aster](https://github.com/aster))
- Add Oak TypeScript AST path for `<script client>` and `<script server>` preflight ([@aster](https://github.com/aster))
- Project `.vmz` scripts into `NyarAnalysisInput` for Nyar backend analysis ([@aster](https://github.com/aster))
- Add `oak-frontend-smoke` conformance gate (adapter, template lowering, Nyar projection) ([@aster](https://github.com/aster))
- Pin Rust nightly for Oak frontend integration ([@aster](https://github.com/aster))

## Bug Fixes

- Harden Oak CST diagnostics and void-element template coverage ([@aster](https://github.com/aster))
- Keep Oak template lowering on smoke gate only — `check` / `compile` use legacy concrete parser ([@aster](https://github.com/aster))
- Temporarily disable CI Format Check until Oak `VueParser` is safe on monorepo `.vmz` walks ([@aster](https://github.com/aster))
- Root-cause Oak hang: `:for` / keyword attribute names never bumped in `parse_attribute` (fixed upstream in `yggdrasil-language/oaks`) ([@aster](https://github.com/aster))
- Remove dynamic-arg skip once Oaks parser handles `:[expr]` / `@[expr]` ([@aster](https://github.com/aster))
- Drop local Oaks `[patch]` so CI resolves git deps from `yggdrasil-language/oaks` ([@aster](https://github.com/aster))
- Remove Oak CST preflight from `vmz format` until Oak `VueParser` loop on real templates is fixed ([@aster](https://github.com/aster))
- Keep Oak TS script AST on smoke gate only — do not block `check` / `compile` on VMZ `#server` / decorator surface ([@aster](https://github.com/aster))
- Strip trailing `}}` from Oak multiline `{{ }}` interpolation spans before oxc expr ingress ([@aster](https://github.com/aster))
- Fix Oaks void-element policy so PascalCase `<Link>` is not swallowed as HTML `<link>` ([@aster](https://github.com/aster))
