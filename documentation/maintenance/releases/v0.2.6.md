# v0.2.6

`@vmz/core` runtime package reshape: layered `browser` / `ssr` / `host` layout, modular `serve-host`, and navigation locale helpers. Homepage commercial/console demo polish and `@vmz/ui-icons` stroke registry.

## Features

- Reshape `@vmz/core` runtime into `browser/`, `ssr/`, `host/`, `faces/`, and `shared` with stable barrels ([@aster](https://github.com/aster))
- Split `serve-host` into `host/serve` modules with shared `serveState` ([@aster](https://github.com/aster))
- Split client navigation into `scroll-focus` and `locale-transition` helpers ([@aster](https://github.com/aster))
- Route `dom.browser` face through `browser/resume` instead of the `ssr` barrel ([@aster](https://github.com/aster))
- Restructure `@vmz/ui-icons` registry with `IconDef` stroke and fill modules ([@aster](https://github.com/aster))
- Render stroke icons in `@vmz/ui-icons` `Icon` with `color: inherit` ([@aster](https://github.com/aster))
- Add filter empty states for console and commercial browse ([@aster](https://github.com/aster))
- Sync commercial featured request and console summary after saving demo notes ([@aster](https://github.com/aster))
- Show sample ticket rows in homepage case study preview ([@aster](https://github.com/aster))

## Bug Fixes

- Restore `serve-host` bootstrap (`listen`, `softReload`, `setServerModuleResolver`) after reshape ([@aster](https://github.com/aster))
- Nest `host-runtime-files.json` paths for `host/serve` and `host/render` delivery companions ([@aster](https://github.com/aster))
- Rewrite nested `host/serve` `vmz-runtime` imports during materialize ([@aster](https://github.com/aster))
- Set `__vmzHostBox = contents` on `@vmz/ui-icons` `Icon` ([@aster](https://github.com/aster))
- Make `@vmz/ui-icons` an optional peer of `@vmz/ui` to avoid workspace cycle ([@aster](https://github.com/aster))
- Bind bare class method calls in Direct template emit so homepage `Icon` SSR renders stroke geometry ([@aster](https://github.com/aster))
- Add `pnpm verify:ci-*` parity entrypoints and poll homepage SSR before R1/R2 inspect ([@aster](https://github.com/aster))
