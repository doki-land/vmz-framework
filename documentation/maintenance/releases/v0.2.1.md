# v0.2.1

Nifty format gate, unified `class`/`style` merge, and `each`/`rowKernel` runtime fixes.

## Features

- Apply `@doki-land/nifty` formatter across workspace sources ([@aster](https://github.com/aster))

## Bug Fixes

- Emit `dom-attr-normalize.js` in delivery dist and rewrite pack companions ([@aster](https://github.com/aster))
- Merge static and dynamic `class`/`style` in Direct emit and runtime ([@aster](https://github.com/aster))
- Short-circuit `build:runtimes` skip without shell `node -e` ([@aster](https://github.com/aster))
- Stabilize each shared `BindingId` flush so sibling item patches run ([@aster](https://github.com/aster))
- Wake each-item patches on outer field writes and wire `hostFields` ([@aster](https://github.com/aster))
- Emit `data-vmz-key` on `SSR` each rows and count `bindingEvals` in `runPatch` ([@aster](https://github.com/aster))
- Align `eachBlock` `SSR` reconcile with `rowKernel` leaf hooks ([@aster](https://github.com/aster))
- Wire `rowKernel` each reconcile when `createItem` is omitted ([@aster](https://github.com/aster))
- Wire `each`-block listeners in `dom-core` `on`/`onMethod` ([@aster](https://github.com/aster))
- Flush `VMZ` combobox before browser `select` option lookup ([@aster](https://github.com/aster))
