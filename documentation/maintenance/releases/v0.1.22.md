# v0.1.22

Plan-only hosts — layout and locale semantics consumed from Rust plans.

## Features

- Normalize ServerArtifact in Rust and expose OffsetIndex via N-API ([@aster](https://github.com/aster))
- Drive cross-SFC script spans from analyze `name_span` ([@aster](https://github.com/aster))
- Peel hosts to Plan-only `layoutChain` and `pathPattern` ([@aster](https://github.com/aster))
- Expose diagnostic `code` `args` `span` on N-API `JsDiagnostic` ([@aster](https://github.com/aster))
- Add `zh-CN` diagnostic catalogs and locale-invariant fixtures ([@aster](https://github.com/aster))
- Add UTF-16 LSP round-trip on `OffsetIndex` ([@aster](https://github.com/aster))
- Emit stable diagnostic codes across compiler and plugins ([@aster](https://github.com/aster))

## Bug Fixes

- Emit DOM companions and skip vendor in locale rewrite ([@aster](https://github.com/aster))
- Pack `unknown-component` companion and fix unit expect ([@aster](https://github.com/aster))

## Breaking Changes

None

## Other

- Register Plan-only host verify gates ([@aster](https://github.com/aster))
