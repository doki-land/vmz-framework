# v0.2.8

Oak/Nyar frontend integration phase B–D completion: Oak-primary script/template analysis, Nyar import projection, oxc residual peels (`useX`/`createX`, method RW, `module_rewrite`, `print_template_expr`), and expanded `template-vue-oak-surface` conformance.

## Features

- Prefer Oak TypeScript for script surface analysis with oxc RW graft for BindingPattern gaps ([@aster](https://github.com/aster))
- Prefer Oak walks for template deps, `this.` field binding, and forbidden `useX`/`createX` factory scan ([@aster](https://github.com/aster))
- Prefer Oak template layers primary for check and compile Semantic ([@aster](https://github.com/aster))
- Lower Oak Vue AST to Semantic without private `ConcreteIr` hop ([@aster](https://github.com/aster))
- Project static / side-effect / `export … from` imports into `NyarProgramUnit.imports` ([@aster](https://github.com/aster))
- Prefer Oak span splice for `module_rewrite` specifier rewrite ([@aster](https://github.com/aster))
- Prefer Oak AST print for `print_template_expr` with oxc codegen fallback ([@aster](https://github.com/aster))
- Expand `template-vue-oak-surface` Vue syntax matrix and pin Oaks `#` / `v-slot` fixes ([@aster](https://github.com/aster))
