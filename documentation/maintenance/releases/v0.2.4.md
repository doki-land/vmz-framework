# v0.2.4

Stable `vmz format` for `.vmz` authoring surfaces, with workspace mass reformat and strict CI format gates restored.

## Features

- Delimit Vue bind attrs with quote-safe emit so dynamic `:class` string concat no longer corrupts on format ([@aster](https://github.com/aster))
- Make SFC envelope assembly idempotent for `<template>`, `<style>`, and JSON5 `<router>` / `<meta>` blocks ([@aster](https://github.com/aster))
- Mass format workspace `.vmz` sources with the stabilized formatter ([@aster](https://github.com/aster))

## Bug Fixes

- Fix `vmz-formatter` `:class` attr quoting when oxc emits double-quoted string literals ([@aster](https://github.com/aster))
- Stop `<style>` and router JSON5 blocks from drifting on repeated `vmz format` ([@aster](https://github.com/aster))

## Breaking Changes

None

## Other

- Re-enable `format.vmz` in `vmz.config.ts` and restore blocking CI Format Check ([@aster](https://github.com/aster))
- Add `vmz-formatter` conformance tests for class binds, router JSON5, style blocks, and deploy planner idempotency ([@aster](https://github.com/aster))
