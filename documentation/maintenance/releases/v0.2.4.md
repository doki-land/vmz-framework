# v0.2.4

Stable `vmz format` for `.vmz` authoring surfaces, homepage request-workflow dogfood, and Shiki-backed code preview on the official site.

## Features

- Delimit Vue bind attrs with quote-safe emit so dynamic `:class` string concat no longer corrupts on format ([@aster](https://github.com/aster))
- Make SFC envelope assembly idempotent for `<template>`, `<style>`, and JSON5 `<router>` / `<meta>` blocks ([@aster](https://github.com/aster))
- Mass format workspace `.vmz` sources with the stabilized formatter ([@aster](https://github.com/aster))
- Show source and interactive result on `@vmz/homepage` with a request workflow case across Commercial and Console ([@aster](https://github.com/aster))
- Wire real Shiki highlighting into the homepage hero code preview ([@aster](https://github.com/aster))
- Turn the product page into a readable UI guide and align homepage navigation with the application case ([@aster](https://github.com/aster))

## Bug Fixes

- Align `Checkbox` `@change` with boolean payload like `Switch` ([@aster](https://github.com/aster))
- Restore dialog opener focus after dismiss in UI lab and automation ([@aster](https://github.com/aster))
- Fix `vmz-formatter` `:class` attr quoting when oxc emits double-quoted string literals ([@aster](https://github.com/aster))
- Stop `<style>` and router JSON5 blocks from drifting on repeated `vmz format` ([@aster](https://github.com/aster))
- Accept parenthesized static `Link` `params` after `vmz format` canonicalize ([@aster](https://github.com/aster))
- Preserve template value imports and fix server-side raw HTML rendering ([@aster](https://github.com/aster))
- Fold template indent newlines while keeping interpolation text contiguous ([@aster](https://github.com/aster))
- Keep laboratory and product content inside the page main ([@aster](https://github.com/aster))

## Breaking Changes

None

## Other

- Re-enable `format.vmz` in `vmz.config.ts` and restore blocking CI Format Check ([@aster](https://github.com/aster))
- Add `vmz-formatter` conformance tests for class binds, router JSON5, style blocks, and deploy planner idempotency ([@aster](https://github.com/aster))
- Add `homepage-ssr-html` highlight check for Shiki output in the first SSR response ([@aster](https://github.com/aster))
- Unify homepage typography rhythm and code preview styling ([@aster](https://github.com/aster))
