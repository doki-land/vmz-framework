# v0.2.3

Commercial visual spec delivery for the official homepage, Console, and Commercial demos, plus conformance evidence for SSR rendering and viewport overflow.

## Features

- Align homepage landing hero, features, showcase, flow, statement, and start sections with commercial visual spec ([@aster](https://github.com/aster))
- Restructure Commercial as browse, detail, and action task walkthrough ([@aster](https://github.com/aster))
- Unify Console release table with six columns, summary panel, and detail drawer ([@aster](https://github.com/aster))
- Extend `ConsoleShell` with breadcrumb, subtitle, and spec shell dimensions ([@aster](https://github.com/aster))
- Add `#server/demo` release workflow fixture shared by homepage, Console, and Commercial ([@aster](https://github.com/aster))
- Centralize homepage demo release seeds in `src/demo/releases.ts` ([@aster](https://github.com/aster))
- Add `commercial-visual-evidence` verify gate and viewport capture script ([@aster](https://github.com/aster))
- Add `homepage-ssr-html` verify gate for live SSR R1 and R2 checks ([@aster](https://github.com/aster))
- Wire `commercial-visual-evidence` into `ui-commercial`, `ui-console`, and `browser-production` ([@aster](https://github.com/aster))
- Trim SiteHeader nav and add mobile menu drawer ([@aster](https://github.com/aster))
- Wire homepage, Commercial, Console, product, and UI lab copy through `#locales` ([@aster](https://github.com/aster))

## Bug Fixes
